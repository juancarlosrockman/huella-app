HUELLA — siguiente paso: conectar Cloudflare D1

IMPORTANTE: este ZIP agrega endpoints de acciones, pero no es producción segura. El ID de dispositivo es pseudónimo y NO equivale a autenticación. No guardar información sensible ni abrir la app al público para uso real todavía.

1. En Cloudflare, Workers & Pages > D1 SQL Database > Create database. Nombre: huella-db.
2. Abre la base de datos > Console y ejecuta el contenido completo de schema.sql.
3. Copia el Database ID de la base D1 (no es un secreto) y reemplaza REPLACE_WITH_D1_DATABASE_ID en wrangler.jsonc por ese ID.
4. En Worker huella-app > Settings > Bindings > Add > D1 database. Variable name: DB. Selecciona la base huella-db y guarda.
5. Actualiza los archivos de GitHub con este ZIP y espera el nuevo despliegue automático. Si Cloudflare pide un build command: npm run build. No añadas tokens de JC Fútbol Coach.
6. Abre https://TU-WORKER.workers.dev/api/health. La respuesta debe indicar "databaseConfigured":true. Después prueba guardar una acción y verla en Mi camino.
